# PlacementHub V2 Agent Guide

PlacementHub V2 is a final-year MERN placement-management project for one college placement cell.

## Working rules

- Complete one roadmap milestone at a time.
- Inspect relevant code and documentation before changing files.
- Keep backend features in domain modules with routes, controller, service, validation, and model responsibilities separated.
- Keep frontend pages, features, API services, and reusable components separated.
- Use Zod for request/form validation and consistent API responses.
- Do not hard-code credentials, API keys, URLs, or business rules that belong in configuration.
- Do not refactor unrelated working code.
- Run appropriate checks and give beginner-friendly manual test steps after each milestone.
- Update documentation when an approved implementation decision changes.
- Wait for the user to approve testing before creating a Git checkpoint or starting the next milestone.

## Source of truth

Read `docs/roadmap.md` for the active milestone. Read the relevant document in `docs/` before changing architecture, data models, APIs, workflows, AI, UI, or security behavior.
